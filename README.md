# Ayesha Anwar — Data Analyst Portfolio

This is the source code for my personal portfolio website.

## Publish with GitHub Pages
1. Create a public repository named `portfolio` under the GitHub account `ayesh6214`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Your website will be available at `https://ayesh6214.github.io/portfolio/`.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
- Replace the LinkedIn placeholder with your LinkedIn URL.
- Replace the sample project links (`href="#"`) with your project repository URLs.
- The dashboard preview visuals are decorative placeholders. Replace them with your actual dashboard screenshots if desired.
- Add your resume PDF to the repository and link it from the page if you want a resume download button.

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
